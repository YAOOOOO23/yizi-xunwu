# 一字寻物

一个公开的中文网页实验：用户写下想到失物时最先确定的一个字，程序依据固定的传统相字条目，给出最多三轮寻物线索。

在线使用：<https://yizi-xunwu.yaoyinboapply.chatgpt.site/>

## 现在能做什么

- 记录本人正在寻找的具体物品
- 手写一个字，并保留原始笔迹与第一笔时间
- 手动填写推演地点，或由用户明确授权浏览器定位
- 确认后一次性计算并封存全部线索，再按轮次揭示
- 在规则依据不足时停止，不用随机方向或生活概率补答案

## 固定边界

- 仅限本人经手后遗失、现在由本人寻找的物品，不开放代找
- 字形以用户实际写下的简体或繁体为准，不暗中转换字形
- 规则引擎负责裁决；没有大模型参与结果生成
- 不以 IP 推测地点，不把手填地点或授权坐标写入数据库
- 不指认任何人；结果不能作为偷窃证据
- 这是传统文化寻物提示，不保证物品一定找回

主要文献依据：[《古今图书集成·艺术典·第748卷·新订指明心法》](https://zh.wikisource.org/zh/%E6%AC%BD%E5%AE%9A%E5%8F%A4%E4%BB%8A%E5%9C%96%E6%9B%B8%E9%9B%86%E6%88%90/%E5%8D%9A%E7%89%A9%E5%BD%99%E7%B7%A8/%E8%97%9D%E8%A1%93%E5%85%B8/%E7%AC%AC748%E5%8D%B7)

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

质量检查：

```bash
npm run lint
npm run build
```

## 当前版本

公开 alpha 0.2。当前规则引擎只实现了能够明确写成确定性程序的保守子集；后续新增规则必须版本化，并通过旧案例回归检查，不能悄悄改变既有结果。
